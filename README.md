# T‑Rooster Tattoo Shop — concept demo

Demo statica e responsive realizzata per mostrare una possibile nuova identità digitale dello studio.

## Avvio

Apri `index.html` oppure carica l'intera cartella nella radice di un repository GitHub Pages. Non sono necessari npm, compilazione o servizi esterni.

## Nota

Questo progetto è un concept non ufficiale. Le immagini di tatuaggi e piercing sono state generate con intelligenza artificiale a scopo dimostrativo e devono essere sostituite con fotografie autorizzate dei lavori reali prima di un'eventuale pubblicazione ufficiale.

## Come trovarci — aggiornamento 25 ottobre 2026
Vista satellitare reale e foto edificio fornite dall’utente. La posizione del richiamo riprende il segnaposto T Rooster Tattoo della vista fornita, non un nuovo rilievo dell’ingresso. Il trattamento visivo è applicato con CSS: la geografia originale resta invariata. Collegamento a Google Maps per il percorso. Per la pubblicazione ufficiale verificare i diritti d’uso delle immagini cartografiche e i contatti con lo studio.
